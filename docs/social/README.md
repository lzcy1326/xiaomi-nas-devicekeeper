## 小红书安全版正文

家里有小米 NAS 的，真的建议装一个。

之前想看 CPU、温度、硬盘状态，得 SSH 进去敲命令；现在直接在米家 App 里打开「设备管家」，一屏全看完。

它能看：

📊 CPU / 内存 / 负载 / 网络速率
🌡️ CPU 温度、硬盘温度、风扇转速
💾 固件存储池、两块硬盘的健康和容量
🐳 Docker 容器状态 + systemd 服务
📈 1 小时 / 24 小时 / 7 天历史曲线
📱 手机和桌面都适配

重点是：只读。
不重启设备、不启停容器、不改风扇、不删文件；数据存在 NAS 本地 SQLite，不上传云端。服务只绑 `127.0.0.1`，走米家 `plugin.cgi` 登录，admin 才能看，普通用户直链 403。

项目已经开源，主页和评论区可以看。

目前在一台四核小米 NAS、1.0.9.462 固件上完成验收；其他型号/固件可能需要适配。需要开发者模式和 SSH，安装脚本一条命令，UID 自己填。

非官方插件，装前先备份，介意慎入。
需要安装教程的评论区扣 1，我整理一份避坑版。

## 发布建议

1. 首图用 `01-cover.png`，标题保持两行大字号。
2. 小红书组图顺序：封面 → 设备概况 → 存储 → 隐私权限 → `05-open-source-safe.png` → 安装提示。
3. 正文保留“只读”和“数据不上云”，这是这个项目最重要的差异点。
4. 如果平台需要方图，首图改用 `00-cover-square.png`。
5. 小红书版不要使用 `05-open-source.png` 的二维码，也不要正文里写 GitHub 或外部网址。
